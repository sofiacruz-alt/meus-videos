# 🎬 Meus Vídeos

## 📖 Sobre o projeto

Este projeto foi desenvolvido como um desafio do curso de **HTML5**, com o objetivo de criar um site onde seja possível indicar quatro vídeos para o visitante.

A página principal apresenta quatro thumbnails. Ao clicar em qualquer uma delas, o visitante é direcionado para uma página específica daquele vídeo.

## 🎯 Objetivos

- Criar uma página principal para indicar quatro vídeos;
- Utilizar imagens como thumbnails dos vídeos;
- Criar uma página específica para cada vídeo;
- Incorporar os vídeos diretamente do YouTube;
- Criar um link para acessar o curso completo;
- Fazer com que o link do curso completo seja aberto em uma nova aba;
- Criar um botão de voltar para a página principal.

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **YouTube**
